# 第1095天 · 零成本 AI 漫剧样片

> 一部用**零成本开源工具链**制作的 60 秒竖屏动态漫样片，验证「故事钩子是否成立」。
> 定位：**故事钩子验证样片，非商业交付**。所有状态为截至 2026-11-19 的核验结果。

## 这是什么

《第1095天》是一个都市情感 / 轻悬疑反转的短篇样片：等待三年的林知夏收到一封无名信，结尾反转揭晓这三年一直守着她的人是谁。

本仓库只包含**源码、创作圣经与构建脚本**（不含二进制素材）。所有图片、音频、视频均可通过下方脚本在本地零成本重新生成。

## 零成本原则

- 不调用付费的生图/生视频服务
- 出图端点 Pollinations 免 key（**已转积分制，不稳定**，见风险）
- 配音用 edge-tts（微软在线 TTS，免费无 Key）
- 合成用 moviepy + ffmpeg（BSD-3 / 免费二进制）
- 无 BGM（规避版权风险）

## 工具链

| 环节 | 工具 | 许可证/条款 |
|---|---|---|
| 剧本/分镜/提示词 | WorkBuddy + 原创创作圣经 | 原创 |
| 画面 | 程序化分镜板（组合 C 降级） | 本项目原创 |
| 配音 | edge-tts | LGPLv3 + 微软在线服务条款 |
| 字幕 | PIL 烧录 + 逐句 SRT | 原创 |
| 剪辑合成 | moviepy + ffmpeg | BSD-3 / 免费二进制 |

## 目录结构

```

scripts/           构建脚本（出图/降级板/字幕/配音/合成/封面）
assets/            运行时生成的素材（.gitignore 排除）
output/            运行时生成的成品（.gitignore 排除）
```

## 本地复现

环境：Python 3.11+（验证环境 3.13）。

```bash
python -m pip install edge-tts moviepy imageio-ffmpeg Pillow
```

按序运行（全部零成本）：

```bash
python scripts/gen_boards.py        # 生成 17 张程序化分镜板（组合 C 降级，稳定可用）
python scripts/gen_voice.py         # edge-tts 生成 17 段配音 + SRT
python scripts/burn_subtitles.py    # PIL 烧录台词字幕
python scripts/compose.py           # 合成 9:16 竖屏 MP4
python scripts/make_cover.py        # 生成发布封面
```

> 说明：`gen_images.py` / `gen_images_slow.py` 是 Pollinations 免 key 出图的尝试，实测触发 HTTP 402 限流且返回图与提示词不符，故主路径已切换为程序化降级板。保留脚本供参考与复核端点状态。

## 风险与限制

1. **画面为降级产物**：程序化色卡分镜板 + 人物剪影，角色一致性弱，非 AI 精细出图，仅用于验证故事钩子。
2. **免费端点不稳定**：Pollinations 已转积分制，随时可能收紧/限流。
3. **在线 TTS 依赖**：edge-tts 依赖微软在线服务，需联网，条款变动影响可用性。
4. **许可证边界**：AGPLv3/GPLv3 约束软件再分发、不传染视频成品；本项目未使用 Fish Audio（其有年营收门槛与署名义务）。商用授权一律复核官方条款。
5. **零费用 ≠ 零成本**：省的是钱，耗的是时间。本样片非商业交付。
6. **时效**：以上为 2026-11-19 核验状态，商用前须全部复核。
